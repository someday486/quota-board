# QuotaBoard 사용 메뉴얼

## 1. 사이트 개요

QuotaBoard는 상담/섭외 운영을 위한 내부 업무 사이트입니다.
주요 기능은 아래 3가지입니다.

- 팀장 지원 현황 확인 및 지역별 지원 등록
- 관리자용 TO 운영, 지원 목록 관리, 인원 제재 관리
- 휴가 및 센터 일정을 한 화면에서 관리하는 캘린더

권한에 따라 보이는 화면이 다릅니다.

- `팀장`: 지원 등록, 본인 지원 내역 확인, 휴가 조회/신청
- `관리자`: 전체 운영 현황 관리, 예비 등록 처리, 인원 관리, 전체 휴가/센터 일정 관리

---

## 2. 로그인 방법

1. 로그인 화면에서 회사 이메일과 비밀번호를 입력합니다.
2. `로그인` 버튼을 누르거나 `Enter` 키를 누릅니다.
3. 권한에 따라 자동으로 해당 화면으로 이동합니다.

- 관리자 계정: `관리자 대시보드`
- 팀장 계정: `팀장 화면`

로그인이 되지 않거나 화면 이동이 되지 않으면 관리자에게 계정 상태를 확인 요청합니다.

---

## 3. 팀장 화면 사용법

### 3-1. 화면 구성

팀장 화면에서는 아래 정보를 확인할 수 있습니다.

- 오늘 지원 가능 여부
- 오늘 지원 가능 조
- 개인 지원 한도
- 무효콜 누적 및 참여 제한 상태
- 지역별 TO와 잔여 수량
- 본인 지원 내역

상단의 `사용 가이드`를 펼치면 기본 사용 순서를 바로 확인할 수 있습니다.

### 3-2. 지역 지원 등록

1. `지역별 배정 가능 수량(TO)` 표에서 지원할 지역을 확인합니다.
2. 해당 지역의 `기업명` 입력칸에 업체명을 입력합니다.
3. `지원` 버튼을 누르거나 `Enter` 키를 누릅니다.
4. 등록이 완료되면 아래 `내 지원 목록`에 바로 반영됩니다.

### 3-3. 지원이 안 되는 경우

아래 조건에서는 지원 버튼이 비활성화되거나 제한 메시지가 표시됩니다.

- 오늘 지원 가능 조가 본인 소속 조와 다를 때
- 1인당 일일 지원 한도에 도달했을 때
- 무효콜 누적으로 참여 제한 중일 때
- 해당 지역이 마감되었을 때

### 3-4. 예비 등록

마감된 지역에 대기 형태로 등록해야 할 경우 `예비등록` 버튼을 사용합니다.

1. `예비등록` 버튼을 누릅니다.
2. 마감된 지역을 선택합니다.
3. 기업명을 입력합니다.
4. `예비 등록` 버튼을 누릅니다.

예비 등록은 별도 승인 개념이 아니라, 관리자가 나중에 정식 등록으로 전환할 수 있는 대기 목록입니다.

### 3-5. 내 지원 내역 확인

화면 하단 `내 지원 목록`에서 아래 내용을 확인할 수 있습니다.

- 지원 시간
- 지역
- 기업명
- 예비 등록 여부

### 3-6. 휴가 화면으로 이동

화면 하단 `휴가 요청` 버튼을 누르면 휴가관리 캘린더로 이동합니다.

## 4. 관리자 대시보드 사용법

### 4-1. 화면 구성

관리자 대시보드에서는 아래 업무를 수행할 수 있습니다.

- 지역별 총 TO 설정
- 1인당 일일 지원 한도 설정
- 오늘 지원 가능한 조 설정
- 팀장별 예외 처리
- 전체 지원 목록 관리
- 예비 등록 목록 처리
- 지원 보드 이미지 복사

### 4-2. 지역별 TO 설정

`지역별 TO` 영역에서 각 지역의 총 TO를 수정할 수 있습니다.

1. 지역별 `총 TO` 값을 입력합니다.
2. 해당 행의 `저장` 버튼을 누르거나, 필요 시 전체 저장을 사용합니다.

주의:

- `초기화`는 전체 TO를 0으로 만들고 현재 지원 내역에도 영향을 줄 수 있으므로 신중히 사용합니다.

### 4-3. 1인당 지원 한도 설정

대시보드 우측 운영 카드에서 `1인당 일일 지원 한도`를 설정할 수 있습니다.

- `0` 입력: 무제한
- `1 이상` 입력: 팀장 1명당 하루 지원 가능 횟수 제한

입력 후 `적용` 버튼을 누릅니다.

### 4-4. 오늘 지원 가능한 조 설정

같은 영역에서 `오늘 지원 조`를 선택할 수 있습니다.

- `전체`: 모든 조 지원 가능
- `1조`: 1조만 지원 가능
- `2조`: 2조만 지원 가능

### 4-5. 팀장별 예외 처리

운영 카드 하단의 팀장 목록에서 개인별 상태를 관리할 수 있습니다.

- 팀장 검색 가능
- 오늘 지원 횟수 확인 가능
- `예외` 체크 시 일일 지원 한도 적용 제외

예외는 운영상 특별 승인 대상에게만 사용합니다.

### 4-6. 전체 지원 목록 관리

`전체 지원 목록`에서 현재 등록된 지원 건을 관리할 수 있습니다.

가능한 작업:

- 지역 필터
- 팀장/기업명 검색
- 미검토 건만 보기
- 기업명 수정
- 녹취 파일 업로드
- 녹취 재생 및 삭제
- 검토 완료 체크
- 지원 제외 처리
- 건별 삭제
- 엑셀 다운로드
- 시트 동기화

#### 녹취 파일 관리

각 지원 건마다 오디오 파일을 등록할 수 있습니다.

- `업로드` 버튼으로 파일 첨부
- `재생` 버튼으로 확인
- `삭제` 버튼으로 제거
- 드래그 앤 드롭 업로드 가능

#### 검토/제외/삭제 차이

- `검토 완료`: 운영 확인 상태 표시
- `제외`: 목록에는 남기되 운영 집계에서 제외할 때 사용
- `삭제`: 지원 자체를 완전히 제거할 때 사용

### 4-7. 예비 등록 목록 처리

`예비 등록 목록`에서는 마감 지역 대기 건을 관리합니다.

가능한 작업:

- `등록`: 예비 등록을 정식 지원으로 전환
- `제외`: 예비 건을 운영 집계에서 제외
- `삭제`: 예비 건 제거

### 4-8. 지원 보드 이미지 복사

하단 `지원 보드(현재)`에서 `보드 이미지 복사` 버튼을 누르면 현재 지원 현황을 이미지처럼 복사해 메신저나 문서에 붙여넣을 수 있습니다.

## 5. 인원 관리 화면 사용법

관리자는 상단 `인원 관리` 메뉴에서 팀장별 제재 상태를 관리할 수 있습니다.

### 5-1. 확인 가능한 정보

- 이름
- 이메일
- 권한
- 소속 조
- 무효콜 누적
- 규정상 제재 기준
- 참여 제한 종료 시각
- 제한 사유 메모
- 현재 상태

### 5-2. 기본 사용 방법

1. 검색어, 조, 무효콜 기준, 제한중 여부로 대상을 필터링합니다.
2. `무효콜 누적` 값을 수정합니다.
3. 필요 시 `참여 제한 종료` 시각을 입력합니다.
4. 메모를 남깁니다.
5. `저장` 버튼을 누릅니다.

### 5-3. 운영 기준

화면 기준상 운영 규칙은 아래와 같습니다.

- 무효콜 `3회 이상`: 1주 제한 기준
- 무효콜 `5회 이상`: 1개월 제한 기준

실제 적용은 저장된 무효콜 수와 참여 제한 종료 시각 기준으로 판단합니다.

## 6. 휴가관리 캘린더 사용법

휴가관리 캘린더는 팀장과 관리자 모두 사용할 수 있습니다.

### 6-1. 화면에서 할 수 있는 일

- 월간 휴가 일정 확인
- 센터 일정 확인
- 본인 휴가 신청
- 관리자용 대리 등록
- 관리자용 센터 일정 등록
- 휴가 상세 조회 및 취소

### 6-2. 화면 보기 기능

상단에서 아래 기능을 사용할 수 있습니다.

- `휴가 보이기/숨기기`
- `센터 일정 보이기/숨기기`
- 월 이동
- 오늘 날짜로 이동

달력 날짜를 클릭하면 등록 동작이 실행됩니다.

- 팀장: 휴가 신청 창 열림
- 관리자 + 휴가 등록 모드: 휴가 등록 창 열림
- 관리자 + 센터 일정 등록 모드: 센터 일정 등록 창 열림

### 6-3. 팀장 휴가 신청

1. 달력에서 날짜를 클릭합니다.
2. 휴가 유형을 선택합니다.

- 연차
- 오전 반차
- 오후 반차

3. 시작일과 종료일을 입력합니다.
4. 필요 시 사유를 입력합니다.
5. `요청하기`를 누릅니다.

주의:

- 반차는 하루만 선택할 수 있습니다.
- 주말에는 신청할 수 없습니다.
- 공휴일은 휴가 차감 대상에서 제외됩니다.
- 이미 겹치는 휴가가 있으면 등록되지 않습니다.

### 6-4. 팀장 본인 휴가 확인

팀장은 달력 아래에서 아래 정보를 확인할 수 있습니다.

- 올해 부여/사용/잔여 휴가
- 올해 휴가 사용 리스트

### 6-5. 관리자 휴가 등록

관리자는 달력에서 직원 대신 휴가를 등록할 수 있습니다.

1. `날짜 클릭 동작`을 `휴가 등록`으로 둡니다.
2. 날짜를 클릭합니다.
3. 대상자를 선택합니다.
4. 휴가 유형과 기간을 입력합니다.
5. `요청하기`를 누릅니다.

### 6-6. 센터 일정 등록

관리자는 센터 일정도 직접 추가할 수 있습니다.

등록 가능한 예:

- 공지
- 회의
- 회식
- 생일
- 포상/기념 일정

사용 방법:

1. `날짜 클릭 동작`을 `센터 일정 등록`으로 변경합니다.
2. 달력 날짜를 클릭하거나 `센터 일정 직접 추가` 버튼을 누릅니다.
3. 일정 제목, 구분, 날짜, 메모를 입력합니다.
4. 필요 시 `매년 반복` 여부를 설정합니다.
5. 저장합니다.

생일 일정은 양력/음력 기준과 윤달 여부까지 설정할 수 있습니다.

### 6-7. 상세 보기와 취소/삭제

달력에 표시된 일정이나 휴가를 클릭하면 상세 창이 열립니다.

- 휴가: 기간, 사용 일수, 사유 확인
- 센터 일정: 구분, 기간, 반복 여부, 메모 확인

관리자는 상세 창에서 아래 작업도 가능합니다.

- 휴가 취소
- 센터 일정 삭제

### 6-8. 관리자 전용 주간 휴가 현황

관리자는 캘린더 하단에서 주간 휴가 사용 현황을 볼 수 있습니다.

가능한 작업:

- 연도 선택
- 주차 선택
- 해당 주 휴가 사용 내역 확인
- `주간 요청 명단 CSV 다운로드`

다운로드 파일에는 이름, 이메일, 휴가 유형, 기간, 제출일이 포함됩니다.

## 7. 운영 시 자주 쓰는 흐름

### 7-1. 팀장 지원 등록

1. 팀장 로그인
2. 오늘 지원 가능 상태 확인
3. 지역 선택 후 기업명 입력
4. `지원`
5. 내 지원 목록 확인

### 7-2. 관리자 운영 시작

1. 관리자 로그인
2. 지역별 TO 점검
3. 오늘 지원 조 설정
4. 1인당 한도 설정
5. 예외 대상 확인
6. 전체 지원 목록 모니터링

### 7-3. 예비 등록 정식 전환

1. `예비 등록 목록` 확인
2. 정식 전환할 건의 `등록` 클릭
3. 전체 지원 목록 및 지원 보드 반영 여부 확인

### 7-4. 휴가 등록

1. `휴가관리 캘린더` 이동
2. 날짜 클릭
3. 유형/기간 입력
4. 저장
5. 달력 반영 여부 확인

---

## 8. 사용 시 주의사항

- 팀장 지원은 기업명을 입력해야 등록됩니다.
- 마감 지역은 일반 지원이 불가하며 예비 등록만 가능합니다.
- 반차는 하루만 등록 가능합니다.
- 주말과 공휴일 규칙을 확인한 뒤 휴가를 등록합니다.
- `삭제` 기능은 되돌리기 어렵기 때문에 신중히 사용합니다.
- 운영 제재는 무효콜 수와 제한 종료 시각을 함께 확인하고 저장합니다.

---

## 9. 추천 배포 형태

이 문서는 아래 형태로 가공하면 실사용자가 보기 더 편합니다.

- `간단본`: 팀장용 1페이지 사용법
- `운영본`: 관리자용 상세 메뉴얼
- `FAQ`: 로그인 안 됨, 지원 안 됨, 휴가 등록 안 됨 같은 자주 묻는 질문

필요하면 다음 단계로 이어서 정리할 수 있습니다.

- 팀장용 메뉴얼만 따로 분리
- 관리자용 운영 SOP 형식으로 재작성
- 캡처 화면 기준 매뉴얼 문구로 축약
