# QuotaBoard 팀장용 사용 메뉴얼

## 1. 이 문서는 누구용인가요?

이 문서는 `팀장 계정` 사용자 전용 메뉴얼입니다.
팀장이 실제로 자주 쓰는 기능만 빠르게 볼 수 있도록 정리했습니다.

주요 사용 기능:

- 로그인
- 지역 지원 등록
- 예비 등록
- 내 지원 내역 확인
- 휴가 조회 및 휴가 신청

---

## 2. 로그인 방법

1. 로그인 화면에서 사번과 비밀번호를 입력합니다.
2. `로그인` 버튼을 누르거나 `Enter` 키를 누릅니다.
3. 로그인 후 자동으로 팀장 화면으로 이동합니다.

로그인이 되지 않으면 관리자에게 계정 상태 확인을 요청합니다.

---

## 3. 팀장 화면에서 하는 일

팀장 화면에서는 아래 내용을 확인하고 사용할 수 있습니다.

- 오늘 내가 지원 가능한 상태인지 확인
- 어느 조만 지원 가능한 날인지 확인
- 오늘 남은 지원 가능 횟수 확인
- 지역별 잔여 TO 확인
- 기업명 입력 후 지원 등록
- 마감 지역 예비 등록
- 내 지원 내역 확인

---

## 4. 지역 지원 등록 방법

### 기본 순서

1. 화면에서 오늘 지원 가능 상태를 먼저 확인합니다.
2. `지역별 배정 가능 수량(TO)` 표에서 지원할 지역을 찾습니다.
3. 해당 지역의 `기업명` 칸에 업체명을 입력합니다.
4. `지원` 버튼을 누르거나 `Enter` 키를 누릅니다.
5. 등록이 완료되면 아래 `내 지원 목록`에 바로 표시됩니다.

### 꼭 확인할 것

- 기업명을 입력해야 지원이 등록됩니다.
- 잔여 수량이 0이거나 마감이면 일반 지원은 불가능합니다.
- 지원 후에는 내 지원 목록에 반영됐는지 확인합니다.

---

## 5. 지원이 안 되는 경우

아래 상황에서는 지원이 제한될 수 있습니다.

- 오늘 지원 가능한 조와 내 소속 조가 다를 때
- 오늘 개인 지원 한도에 도달했을 때
- 무효콜 누적으로 참여 제한 중일 때
- 해당 지역이 이미 마감되었을 때

화면 상단 상태 요약 카드에서 현재 제한 사유를 먼저 확인하면 빠릅니다.

---

## 6. 예비 등록 방법

마감된 지역에 대기 형태로 올려야 할 경우 `예비등록`을 사용합니다.

1. `예비등록` 버튼을 누릅니다.
2. 마감된 지역을 선택합니다.
3. 기업명을 입력합니다.
4. `예비 등록` 버튼을 누릅니다.

예비 등록은 즉시 정식 지원이 되는 것이 아니라, 관리자가 나중에 정식 등록으로 전환할 수 있는 대기 목록입니다.

---

## 7. 내 지원 내역 확인

화면 하단 `내 지원 목록`에서 아래 내용을 확인할 수 있습니다.

- 지원 시간
- 지역
- 기업명
- 예비 등록 여부

지원한 내용이 보이지 않으면 새로고침 후 다시 확인하고, 그래도 없으면 관리자에게 문의합니다.

---

## 8. 화면에서 자주 보는 정보

### 오늘 지원 가능 조

- `전체`면 모든 조가 지원 가능합니다.
- `1조` 또는 `2조`로 표시되면 해당 조만 지원 가능합니다.

### 오늘 남은 지원 가능 횟수

- 숫자가 표시되면 오늘 남은 지원 가능 횟수입니다.
- `무제한`이면 일일 제한 없이 지원 가능합니다.
- `예외` 표시가 있으면 한도 제한 대상이 아닙니다.

### 무효콜 / 참여 제한

- 무효콜 누적 수가 표시됩니다.
- 참여 제한 중이면 종료 시각이 함께 안내됩니다.
- 참여 제한 중에는 지원 등록과 예비 등록이 모두 제한될 수 있습니다.

---

## 9. 휴가 신청 방법

팀장 화면 하단 `휴가 요청` 버튼을 누르면 휴가관리 캘린더로 이동합니다.

### 휴가 신청 순서

1. 달력에서 원하는 날짜를 클릭합니다.
2. 휴가 유형을 선택합니다.

- 연차
- 오전 반차
- 오후 반차

3. 시작일과 종료일을 입력합니다.
4. 필요하면 사유를 입력합니다.
5. `요청하기` 버튼을 누릅니다.

### 휴가 신청 시 주의사항

- 반차는 하루만 선택할 수 있습니다.
- 주말에는 휴가 신청이 불가능합니다.
- 공휴일은 휴가 차감 대상에서 제외됩니다.
- 이미 겹치는 휴가가 있으면 등록되지 않습니다.

---

## 10. 휴가 화면에서 확인할 수 있는 것

휴가관리 캘린더에서는 아래 내용을 볼 수 있습니다.

- 월간 휴가 일정
- 센터 일정
- 내 올해 휴가 부여/사용/잔여 현황
- 내 휴가 사용 리스트

달력에서 등록된 휴가나 일정을 클릭하면 상세 내용을 확인할 수 있습니다.

---

## 11. 팀장이 자주 쓰는 흐름

### 지원 등록할 때

1. 로그인
2. 오늘 지원 가능 상태 확인
3. 지역 선택
4. 기업명 입력
5. `지원`
6. 내 지원 목록 확인

### 마감 지역 처리할 때

1. 마감 여부 확인
2. `예비등록`
3. 지역 선택
4. 기업명 입력
5. 예비 등록 완료 확인

### 휴가 신청할 때

1. `휴가 요청` 이동
2. 날짜 클릭
3. 휴가 유형 선택
4. 기간 입력
5. `요청하기`

---

## 12. 자주 생기는 실수

- 기업명 입력 없이 바로 지원 버튼을 누름
- 오늘 지원 가능한 조를 확인하지 않음
- 남은 지원 가능 횟수를 확인하지 않음
- 마감 지역인데 일반 지원을 시도함
- 반차인데 날짜를 여러 날로 선택함
- 주말에 휴가를 등록하려고 함

---

## 13. 문제가 있을 때 확인 순서

### 지원 버튼이 안 눌릴 때

1. 오늘 지원 가능한 조인지 확인
2. 개인 한도 초과 여부 확인
3. 참여 제한 상태인지 확인
4. 지역이 마감인지 확인
5. 기업명을 입력했는지 확인

### 휴가 신청이 안 될 때

1. 주말 선택 여부 확인
2. 반차를 여러 날로 선택했는지 확인
3. 이미 같은 기간 휴가가 있는지 확인
4. 공휴일만 선택한 건 아닌지 확인

---

## 14. 한 줄 요약

팀장은 `오늘 지원 가능 상태 확인 → 기업명 입력 후 지원 → 내 지원 목록 확인` 이 기본 흐름이고,
휴가는 `달력 날짜 클릭 → 유형 선택 → 요청하기` 순서로 사용하면 됩니다.
